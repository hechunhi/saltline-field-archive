# 模块拆分回归记录

日期：2026-11-10。以已恢复、未改动玩法的本地版本为重构前基线；原始发布文件仍保存在 `archive/original.html`。

## 变更

- 将原来 72,964 行的单一 `src/game.js` 拆为 66 个 ES 模块；启动入口现为 6 行。
- 原版 Three.js r180 独立到 `src/vendor/three-r180.js`，导出标准类型名；保留其许可文本。
- 渲染、程序化材质、道具/关卡/远景/地面、音频、特效、输入、玩家、武器、敌人、HUD/菜单和游戏流程分别归入对应目录。
- 主要工厂函数、引擎导入和 context 参数改为可读名称；没有升级引擎或改动画面、着色器、物理、关卡及玩法数值。
- 道具 builder 的原有覆盖顺序在 `world/props/register.js` 中显式保留。
- 增加所有模块的导入/导出、循环依赖和导入绑定赋值检查，以及可选的原件结构审计。

模块和接口说明见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 代码与构建检查

通过 `npm run check`、`npm run verify:refactor` 和 `npm run build`。

结构审计将 66 个模块中的 **2,069 条原始语句**逐一对应回不可变的原始归档，确认表达式、常量、着色器/模板字符串及词法绑定保持一致。仅接受模块边界、作用域内的标识符改名，以及代码生成器为明确 else 归属添加的空作用域包装。

所有原始语句恰好覆盖一次，无循环依赖、缺失命名导出、新增未解析引用或跨模块变量赋值。结果见 `refactor-structure.json`，对应关系见 `scripts/refactor-map.json`。

构建通过，Vite 处理 71 个模块（含样式和构建辅助模块），输出 JS 约 1.38 MB（gzip 约 429 KB），CSS 和本地字体保留。生产仍会出现默认的大 chunk 提示。

## 范围

本次做了结构等价审计、固定场景比较和实时键盘/UI 回归，没有重新通关全部任务，也没有新增移动设备或实体手柄验收。内嵌浏览器仍未提供鼠标捕获，转向和射击使用原版的方向键/Enter 替代操作；独立浏览器 Pointer Lock 和听觉品质未单独评估。

`verify:refactor` 用于证明这次迁移与原件一致；后续有意修改玩法时可能失败，因此不属于日常 `check`。原始归档和本次基线应作为历史证据保留。
